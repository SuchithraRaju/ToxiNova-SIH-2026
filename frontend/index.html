System workflow

StagePrototype action
1. WearPassive colorimetric H₂S strip worn during shift
2. ExposureH₂S causes progressive color response
3. ScanSupervisor/worker photographs strip with smartphone
4. CVOpenCV-style pixel extraction → CIELAB → ΔE
5. QuantifyCalibration curve converts color response to estimated ppm-hours
6. StoreWorker-wise result saved locally; sync when network returns
